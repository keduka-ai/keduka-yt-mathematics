Welcome to the **Mathematics for ML** repository. This project serves as a structured, end-to-end educational roadmap designed to take a learner from elementary arithmetic to advanced university-level mathematics and its direct applications in Artificial Intelligence, Deep Learning, and Computational Physics.

The curriculum is meticulously organized into six parts, progressing through levels of complexity while highlighting the specific relevance of each topic to Machine Learning (ML).
